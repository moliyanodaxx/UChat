## 用户系统

### 注册与登录

**注册新账号**
1. 输入10位字母或数字的账号
2. 设置8-10位字母或数字的密码
3. 首次登录需设置昵称和头像

**登录已有账号**
- 使用已注册的账号和密码登录
- 支持自动重连，断线后自动恢复

### 个人资料

可设置和修改：
- **昵称**：显示名称，最多20个字符
- **头像**：从16个表情中选择
- **个性签名**：自我介绍，最多100字符

**修改方式**：
- Web端：点击个人中心图标👤
- Android端：进入设置页面
- AI助手：对UU说"把我的昵称改成xxx"

## 房间管理

### 系统房间

**在线聊天室**（ID: 0000000000）
- 所有用户默认加入
- 公共聊天空间
- 无法退出

**系统消息**（ID: 0000000001）
- 接收系统通知
- 房间邀请消息
- 好友请求通知

### 创建房间

**通过界面创建**：
1. 点击"创建房间"按钮➕
2. 输入房间名称（必填）
3. 可选：自定义10位数字房间号
4. 设置6位密码（可选）

**通过AI助手创建**：
```
"帮我创建一个技术交流房间"
"创建一个有密码的房间，叫'私密空间'，密码123456"
```

**房间设置**：
- 房主可修改房间密码
- 房主可设置违禁词
- 房主可踢出成员
- 房主可转让房主权限

### 加入房间

**方式一：输入房间号**
1. 点击"加入房间"按钮🔍
2. 输入10位房间号
3. 如需密码，输入6位密码

**方式二：接受邀请**
1. 好友发送房间邀请
2. 在"系统消息"中查看邀请
3. 点击"接受"加入房间

**方式三：AI助手**
```
"加入房间1234567890"
"加入房间ID为xxx，密码是123456"
```

### 房间操作

**切换房间**
- 点击左侧房间列表切换
- 显示当前房间名称和在线人数

**查看成员**
- 点击右上角⋮按钮
- 查看所有成员列表
- 显示在线状态和房主标识

**退出房间**
- 点击"退出房间"按钮
- 系统房间无法退出

**房主专属功能**：
- 踢出成员
- 转让房主
- 修改房间密码
- 管理违禁词

## 消息功能

### 发送消息

**文字消息**：
- 输入框输入文字
- 按Enter或点击发送按钮
- 最大长度无限制

**表情消息**：
- 点击😊按钮打开表情选择器
- 选择表情插入到消息中
- 支持7个分类，112个表情

**@提及功能**（Android端）：
- 右键点击用户头像
- 选择"@提及"
- 自动在输入框插入@用户名

### 接收消息

**消息显示**：
- 自己的消息：右侧蓝色气泡
- 他人的消息：左侧灰色气泡
- 显示发送者昵称和头像
- 显示发送时间

**系统播报**：
- 用户进入/离开提示
- 3秒后自动消失
- 不保存到历史记录

### 历史消息

- 切换房间时自动加载
- 保留最近100条消息
- 按时间顺序显示

## 好友系统

### 搜索用户

1. 点击好友按钮👥
2. 切换到"搜索用户"标签
3. 输入账号或昵称搜索
4. 点击搜索结果查看详情

### 添加好友

**发送好友请求**：
1. 搜索到目标用户
2. 点击"添加好友"按钮
3. 等待对方接受

**接受好友请求**：
1. 切换到"好友请求"标签
2. 查看待处理的请求
3. 点击"接受"或"拒绝"

### 好友管理

**查看好友列表**：
- 显示所有好友
- 显示在线状态
- 点击查看好友详情

**好友操作**：
- 查看好友资料
- 邀请好友加入房间
- 删除好友（Android端）

### 邀请好友

1. 在房间详情点击"邀请好友"
2. 选择要邀请的好友
3. 好友在系统消息中收到邀请
4. 好友可选择接受或拒绝

## AI助手

### 使用UU

**打开AI助手**：
- Web端：点击侧边栏🤖按钮
- Android端：房间列表右上角机器人图标

**对话方式**：
- 输入自然语言指令
- UU理解意图并执行操作
- 返回执行结果

### 支持的操作

**1. 创建房间**
```
"帮我创建一个名为'技术交流'的房间"
"创建一个房间，名字叫开发讨论"
"创建有密码的房间，叫'私密群'，密码123456"
```

**2. 加入房间**
```
"加入房间1234567890"
"加入ID为xxx的房间"
"加入房间xxx，密码是123456"
```

**3. 发送消息**
```
"在技术交流房间发送'大家好'"
"帮我在当前房间说hello"
"发送消息：今天天气真好"
```

**4. 更新资料**
```
"把我的昵称改成小明"
"修改个性签名为'热爱编程'"
"更新我的昵称和签名"
```

### 注意事项

- UU只能帮助使用UChat功能
- 需要服务器配置有效的API密钥
- 每次请求可能需要几秒钟
- 操作结果会立即反馈

## 高级功能

### 违禁词管理

**房主专属功能**：
1. 打开房间详情
2. 点击"设置违禁词"
3. 添加需要过滤的词语
4. 删除已有违禁词

**效果**：
- 成员发送包含违禁词的消息会被拦截
- 发送者收到拦截提示
- 消息不会被其他人看到

### 断线重连

**自动重连**：
- 网络断开后自动尝试重连
- 3秒后开始重连
- 保持登录状态
- 恢复房间列表

**重连提示**：
- "已断开连接，3秒后重连..."
- "已连接到服务器"

### 消息通知

**系统消息**：
- 好友请求通知
- 房间邀请通知
- 未读标记提示

**实时播报**：
- 用户进入/离开提示
- 3秒自动消失
- 顶部浮动显示

### 多设备管理

**登录检测**：
- 检测同账号多设备登录
- 自动断开旧连接
- 保护账号安全

## 使用技巧

1. **快速切换房间**：使用键盘方向键（部分客户端）
2. **快速发送消息**：按Enter键直接发送
3. **使用AI助手**：复杂操作用自然语言描述
4. **查看历史消息**：切换到对应房间自动加载
5. **管理好友**：定期整理好友列表
6. **房间密码**：重要房间设置密码保护

## 常见问题

**Q: 忘记密码怎么办？**
A: 当前版本不支持密码找回，请妥善保管密码。

**Q: 如何删除已发送的消息？**
A: 当前版本不支持撤回消息。

**Q: AI助手不响应怎么办？**
A: 检查服务器是否配置了有效的API密钥。

**Q: 房间人数有限制吗？**
A: 理论上无限制，但过多用户会影响性能。

**Q: 可以私聊吗？**
A: 当前版本不支持一对一私聊，可创建私密房间。
